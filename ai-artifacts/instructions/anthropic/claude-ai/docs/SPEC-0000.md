# SPEC-NNNN: <what is to be achieved, as a short noun phrase>

A SPEC records what was supposed to be achieved, before any option is chosen.
Where several options satisfy it and one is picked, that pick is an ADR that
cites this SPEC.

## Goal

The state wanted, in the vocabulary of the world: no mechanism, no mention of
the obstacle.

## Scope

- In: what the goal covers.
- Out: what it deliberately does not.

## Acceptance

What counts as done, stated before the work starts. Each line is checkable by
someone who did not do the work.

## Constraints

Rules the solution must keep: format, location, tooling, compatibility.

## Decisions

ADRs that chose between options under this SPEC, one per line: ADR-NNNN - <slug>.
